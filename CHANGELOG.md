# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

### Changed

- Renamed the PyPI distribution to `promptsmith-ai` to avoid a collision with an
  unrelated `promptsmith` package. The `promptsmith` Python import and CLI remain
  unchanged.
- Documented that provider cost figures are estimates and that benchmarks are
  executed locally rather than published as project-wide performance claims.
- Added isolated-install and distribution build checks to CI.

### Added
